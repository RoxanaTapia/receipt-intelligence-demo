# Demo seed receipts

Public-safe **fictional** fixtures for the visitor seeded-examples path.

- Merchants and line items are invented (not real retailers or customer data).
- Amounts are **demo currency (DC)** — not EUR or USD. The UX labels them as DC.
- Dates sit in the demo analytics window (`DEMO_START_DATE` / `DEMO_END_DATE`).

Copy into the shared volume with `./deploy/seed-demo-data.sh`.

The live portfolio sample PDF is separate (`demo/samples/05-demo-basket.pdf`); it is not one of these seed files.
